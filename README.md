AGENDAMENTO DE HORÁRIO DA SALA DE ESTUDO EM GRUPO DA BIBLIOTECA
-----------------------------------------------------------------------------------------------------
  - Descrição:
O projeto tem como finalidade o agendamento da sala de estudos em grupo, de forma formalizada

  - Objetivos
Uma maior organização e segurança evitando choques de horários entre grupos distintos ao realizar o agendamento de uma forma informal

  - Funcionalidades:
Tela de login;
Funcionalidade de sair da conta (logout);
Favoritar livros;
Pesquisa de livros por título ou autor;
Organização dos livros por gêneros;
Página inicial da biblioteca;
Página de perfil do aluno.

    No entanto, nossa principal prioridade neste momento é desenvolver o sistema de agendamento de       horários,
    que precisará de um banco de dados para armazenar e organizar as informações. Além disso, ao         longo do desenvolvimento, 
    novas funcionalidades poderão ser adicionadas para ampliar os recursos e melhorar a experiência      dos usuários.

  - Tecnologias utilizadas:
Está sendo usado com as linguagem de programação; HTML, Django, CSS e Banco de Dados.

  - Pré-requisitos:
É necessário ter o VS code, Python, Django, github e navegador e internet. 

  - Instalação e execução:

Com o VS Code aberto e o link do repositório do GitHub copiado, abra o terminal e digite `git clone LINK_DO_REPOSITORIO`, substituindo o texto pelo link do repositório. Após clonar o projeto, entre na pasta criada utilizando o comando `cd NOME_DA_PASTA`.
Em seguida, crie o ambiente virtual com o comando `python -m venv venv` e ative-o utilizando `venv\Scripts\activate`. Com o ambiente virtual ativado, instale as dependências do projeto através do comando `pip install -r requirements.txt`, que irá ler o arquivo e instalar todas as bibliotecas necessárias, incluindo o Django.
Após a instalação, digite `python manage.py runserver` no terminal e aguarde até que o Django inicie o servidor. Quando aparecer a mensagem indicando que o servidor está rodando, o projeto estará pronto para ser acessado.
Por fim, abra o navegador e digite o endereço `http://localhost:8000/`. Se todas as etapas forem realizadas corretamente, a tela inicial do projeto será exibida, indicando que a aplicação está funcionando localmente.
