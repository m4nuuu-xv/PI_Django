AGENDAMENTO DE HORÁRIO DA SALA DE ESTUDO EM GRUPO DA BIBLIOTECA
-----------------------------------------------------------------------------------------------------
  - Descrição:
O projeto tem como finalidade o agendamento da sala de estudos em grupo, de forma formalizada

  - Objetivos
Uma maior organização e segurança evitando choques de horários entre grupos distintos ao realizar o agendamento de uma forma informal

  - Funcionalidades:
Tela de login;
Funcionalidade de sair da conta (logout);
Favoritar livros;
Pesquisa de livros por título ou autor;
Organização dos livros por gêneros;
Página inicial da biblioteca;
Página de perfil do aluno.

    No entanto, nossa principal prioridade neste momento é desenvolver o sistema de agendamento de       horários,
    que precisará de um banco de dados para armazenar e organizar as informações. Além disso, ao         longo do desenvolvimento, 
    novas funcionalidades poderão ser adicionadas para ampliar os recursos e melhorar a experiência      dos usuários.

  - Tecnologias utilizadas:
Está sendo usado com as linguagem de programação; HTML, Django, CSS e Banco de Dados.

  - Pré-requisitos:
É necessário ter o VS code, Python, Django, github e navegador e internet. 

  - Instalação e execução:
Com o VS code aberto e o link do repositório do GitHub copiado, digite o seguinte comando no terminal "git clone LINK_DO_REPOSITORIO", feito isso, entre na pasta do projeto "cd NOME_DA_PASTA", ative o ambiente virtual "venv\Scripts\activate",
pos isso, use o comando "pip install -r requirements.txt", esse comando vai ler o arquivo e instalar todas as dependências listadas nele, incluindo o Django. Com todas as dependências instaladas e o ambiente virtual ativado, no terminal digite "python manage.py runserver",
aguarde até que o Django inicie o servidor, quando aparecer uma mensagem indicando que o servidor está rodando, significa que o projeto está pronto para ser acessado então abra o navegador e digite o seguinte endereço "http://localhost:8000/", a tendencia é que se tudo ocorrer bem
apareça a tela inicial do projeto.
